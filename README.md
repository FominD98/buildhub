# BuildHub - WPF Application

Современное WPF приложение с дизайном в стиле BuildHub.

## Особенности

- Закругленные углы окна
- Полупрозрачный фон
- Современный дизайн в темной теме
- Двухпанельный layout:
  - Левая панель: список проектов с поиском и фильтрацией по датам
  - Правая панель: рабочая зона с welcome экраном и быстрыми действиями

## Технологии

- .NET 8.0
- WPF (Windows Presentation Foundation)
- XAML

## Запуск приложения

### Сборка проекта
```bash
dotnet build BuildHub.csproj
```

### Запуск приложения
```bash
dotnet run --project BuildHub.csproj
```

Или запустите из Visual Studio, открыв файл `BuildHub.csproj`.

## Структура проекта

```
Tatarsan/
├── App.xaml                 - Определение приложения
├── App.xaml.cs             - Code-behind для App
├── MainWindow.xaml         - Главное окно UI
├── MainWindow.xaml.cs      - Code-behind для MainWindow
├── RectConverter.cs        - Конвертер для закругленных углов
└── BuildHub.csproj         - Файл проекта
```

## UI Компоненты

### Шапка (Header)
- Логотип BuildHub
- Кнопки управления окном (свернуть, развернуть, закрыть)
- Аватар пользователя

### Левая панель (Projects)
- Поиск по проектам
- Список проектов с группировкой по датам:
  - Today
  - Yesterday
  - 3 days ago
  - 7 days ago
- Баннер подписки внизу

### Правая панель (Workspace)
- Welcome экран с приветствием
- Поле ввода с AI индикатором
- Три быстрых действия:
  - Поиск поставщиков
  - Выбор материалов
  - Расчет стоимости

## Возможности окна

- Перетаскивание: зажмите левую кнопку мыши на любом месте окна
- Изменение размера: стандартное изменение размера WPF окна
- Управление: кнопки минимизации, максимизации и закрытия в правом верхнем углу
